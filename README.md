# RESMİ RÜYA ONAY MERKEZİ

## 1. Kuruluş Gerekçesi

Vatandaşın gece gördüğü rüyalar uzun yıllardır denetimsiz kalmıştır. Uçan evler, konuşan balıklar, sınava geç kalanlar ve merdivenleri bitmeyen okullar hiçbir resmi evraka bağlanmamıştır. Bu durum kamu düzeni açısından kabul edilemezdir.

Bu yazılım, rüyayı **onaylar**, **reddeder** veya **Ek Protokol-7'ye** sevk eder. Karar kesindir. İtiraz ancak ikinci bir rüya ile yapılabilir.

## 2. Yasal Dayanak (Hayali)

- Rüya Sicil Kanunu (taslak)
- Uyku Güvenliği Yönetmeliği madde 3/ç
- Gökyüzü Kira Sözleşmesi genel şartnamesi (ilgisi yoktur ama durur)

## 3. Kurulum

```bash
python3 ruya_onay.py
```

Python 3 yeterlidir. Ek paket yok. Bürokrasi sade tutulmuştur.

## 4. Kullanım

Program rüyanızı sorar. Siz yazarsınız. Sistem damga basar.

Örnek kararlar:
- ONAYLANDI
- REDDEDİLDİ (gerekçe: fazla uçuş sahnesi)
- EK PROTOKOL-7 (rüya teknik incelemede)
- MÜHÜR BEKLİYOR (çay molası)

## 5. Mimari İlke

Karar algoritması bilimsel değildir. Bilinçli olarak keyfidir. Keyfilik, resmiyetin özüdür.
